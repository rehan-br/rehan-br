## 🧭 Principles

- **Push authorization into the data layer.** If the UI is the only thing enforcing a rule, it isn't enforced.
- **A model can phrase an answer, never invent one.** Every fact a user sees traces back to code that computed it.
- **Build the harness before trusting the result.** A comparison that can't produce a negative result isn't a comparison.
- **Ship the finished small thing over the impressive unfinished one.**
